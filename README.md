# 圆桌审判

一个用 Godot 4.7 做的 Windows 单机科幻狼人杀演出样片：12 个 AI 拟人角色围坐在钟面圆桌旁，白天是环形讲台，夜晚席位闭合为隔离舱。目前是固定剧本的演示，规则和 AI 还没接。
